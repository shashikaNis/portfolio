# Shashika Kulasekara · Portfolio

Personal portfolio site built with [Next.js](https://nextjs.org) (App Router, TypeScript), deployed on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Editing content

All text, projects, skills and links live in [`data/portfolio.ts`](data/portfolio.ts).
The photo and CV are in `public/` (`profile.webp`, `cv.pdf`).

## Deploy

Push to the `main` branch. Vercel rebuilds and redeploys automatically.
